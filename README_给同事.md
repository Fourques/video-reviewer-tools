# 给审核同事的简明说明

## 开始前

1. 把收到的压缩包完整解压，不要直接在压缩包里运行。
2. 电脑需要 Python 3.10+、FFmpeg 和现代浏览器。
3. 视频和标签只在运行脚本的电脑上处理，不会上传。

## 如何启动

- Windows：双击 `start_windows.bat`。
- macOS / Linux：终端进入工具目录，运行 `./start_mac_linux.sh`。
- VS Code 远程服务器：运行 `./start_remote.sh`。

浏览器打开后，在“视频审核项目中心”中：

1. 选择或粘贴项目目录。
2. 选择审核功能。
3. 确认自动填写的输出位置，需要时可以修改。
4. 点击“开始审核”。

工具只扫描所选目录第一层的视频，不会进入子目录。最近项目、审核功能和自定义输出位置会自动记住。

## 重要操作

- 固定 8 秒模式：`S` 播放/暂停，方向键前后 1 秒，`A/D` 移动 8 秒窗口 5 秒，`W` 循环预览，空格提交片段，回车完成并下一个。没有片段时回车会标记整段无跌倒。
- Fall 快速分类：`S` 播放/暂停，方向键前后 1 秒，`A/D` 前后 5 秒，空格标记 Fall，回车标记非 Fall，随后自动进入下一个。
- 页面上的“提交/标记”会立即保存审核进度；完成后仍要点击“导出”按钮才会生成或复制最终视频。
- 按 `Ctrl+C` 停止，再重新运行并选择相同项目即可恢复进度。

输出视频保持原画质：8 秒片段不重新编码，完整视频按原始字节复制。
