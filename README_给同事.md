# VideoReviewer 2.0 简明操作

1. 下载自己系统的包，完整解压，双击程序；无需安装 Python 或 FFmpeg。
2. 选择数据项目目录。新项目选“跌倒分类 / 区间精选 / 通用标注”模板；旧项目自动恢复已有规则。
3. 默认输出在数据目录内的 `output/`，以后可在“项目设置”修改。只读当前目录第一层视频。

常用按键：S 播放暂停，W 循环，A/D 默认前后 1 秒，J/K/L 默认跌倒 / 不跌倒 / 护工 Fall，U 待复核，[/] 上下视频，Backspace 撤销。区间开启后 Space 添加区间，Enter 完成并下一条。**没选片段不代表无跌倒。** 按键、标签及判定说明均可在项目设置修改并保存为模板。

连续切换会继承倍速、播放暂停和循环，自动兼容无法直接播放的视频。辅助标签和原始 CSV 对照只作说明，不进入文件名；CSV 最多选 3 个展示字段，设备 ID 可搜索、分组。原始 CSV 不修改。

标注实时保存，确认顶栏为“已保存”。**提交不等于整理**：完成后点“整理文件”，核对计划并确认，才把已完成整段视频移动 / 复制到标签子目录。待复核与未审核留在原处。片段默认统一放 `output/clips`，单段原名、多段加 `_0001`；不重新编码，但切点受关键帧限制，可能不是精确 8.000 秒。

进度在数据目录的隐藏 `.video-reviewer/`。更新只替换程序，重新打开原数据目录；迁移数据时连隐藏目录一起保留。v1 隐藏进度自动迁入并保留旧文件。不要让两个程序同时写同一项目。

关闭本机应用窗口会释放服务；未保存或整理中会阻止误关。远程使用在浏览器点“退出工具”最明确，普通关闭最后一页后约 8–12 秒停止。若保存失败，先点击顶栏错误提示重试，必要时下载未保存记录，不要直接清理浏览器数据。

远程目录选择看到的是服务器，不是自己电脑。更详细的路径、系统提示、SSH 与源码运行方式见 `README.md`。
